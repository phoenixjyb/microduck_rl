candidate remains below .27 even in body coordinates, so heading drift alone
cannot explain the remaining speed deficit. Heading improved substantially,

the same as lateral path displacement. This run retained absolute-velocity
summaries, not a signed trajectory, so it cannot distinguish net side drift
from oscillation. **Do not weaken the closed gate or claim a route-offset
diagnosis from these summaries.** A future measurement contract can retain
signed velocity and route-relative position in addition to the existing gate.
