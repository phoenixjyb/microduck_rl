## Conditional arithmetic model

All gradient inputs must be finite exact binary32 values. Model the expression
left to right as `RN(RN(Ma - smooth) - constraint)`, RNE with gradual underflow.
Preserve IEEE zero signs: -0 minus +0 minus +0 is -0; cancellation of finite
nonzero values rounds to +0. Reject non-binary32/type errors, nonfinite values
and intermediate overflow. This is a declared model, not evidence of actual
compiler reassociation, device FTZ/rounding or driver-resident code.

For each world, round each of twenty `grad*grad` products to binary32. Let S be
their exact rational sum, n=20, u=2^-24, and
`B = n*u/(1-n*u)*S + n*2^-149`. An observed norm is conditionally consistent
within `[max(0,S-B),S+B]`; exact Fractions decide, not displayed float endpoints.
Require finite nonnegative outputs and literal positive zero when zero.
Reject squared-product overflow and envelopes reaching the overflow midpoint.
The arbitrary serial order of nonnegative RNE adds is deliberately not exact
bit-qualified; tests include two legal orders producing different norm bits.
This model does not observe CUDA atomic ordering or guarantee arbitrary generated
lowerings. It never widens an old trajectory tolerance.
